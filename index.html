Laptop Site Blocking — Hosts File Guide

Open this page on any agent laptop, follow the steps below, and copy-paste the domain lists into the hosts file.

Steps

  1. Log in using the admin account.
  2. Click Start, type Notepad, right-click it → Run as administrator.
  3. Inside Notepad: File → Open.
  4. Navigate to C:\Windows\System32\drivers\etc\
  5. Change the file filter (bottom-right dropdown) from "Text Documents" to All Files.
  6. Open the file named hosts (no extension).
  7. Copy the domain list below (use the "Copy" button) and paste it at the bottom of the file.
  8. Save (Ctrl+S).
  9. Open Command Prompt as administrator and run:
    ipconfig /flushdns
  10. Test a couple of sites (e.g. youtube.com, betway.co.zm) in the agent's browser — they should fail to load.

Known Gotchas

  • Missing "www." — the hosts file needs an exact match. If a site still loads, check the browser's address bar for the exact domain (with or without www) and compare against this list.
  • Local country domains — some betting sites use a Zambia-specific address (e.g. betway.co.zm, betpawa.co.zm) separate from their global .com. If a site still works, check if it's using a local domain not yet on this list.
  • Secure DNS (DoH) — if Chrome or Edge has "Use secure DNS" turned on, it can bypass the hosts file entirely. Check Settings → Privacy and Security → Security in both browsers.
  • BlueStacks (Android emulator) — if used for WhatsApp, it runs its own network stack and does NOT respect the Windows hosts file. Apps installed inside it (YouTube, Instagram, games, etc.) will bypass everything above. Prefer WhatsApp Desktop or web.whatsapp.com instead if possible.
  • After any edit: always ipconfig /flushdns and fully close/reopen the browser before testing.
