Laptop Site Blocking Guide — Back Office Operations

Open this page on any agent laptop. Follow the steps once, then expand only the categories you need and copy them into the hosts file.

Steps — Site Blocking

  1. Log in using the admin account.
  2. Click Start, type Notepad, right-click it → Run as administrator.
  3. Inside Notepad: File → Open.
  4. Navigate to C:\Windows\System32\drivers\etc\
  5. Change the file filter (bottom-right dropdown) from "Text Documents" to All Files.
  6. Open the file named hosts (no extension).
  7. Expand a category below, hit Copy, and paste it at the bottom of the file — or use Copy All for everything at once.
  8. Save (Ctrl+S).
  9. Open Command Prompt as administrator and run: ipconfig /flushdns
  10. Test a couple of sites (e.g. youtube.com, betway.co.zm, whatsapp.com) in the agent's browser — they should fail to load.

USB & External Device Blocking

This locks down removable storage (USB flash drives, external hard drives) and phones/MTP devices from being read or written on the laptop. Keyboards, mice, and other standard peripherals are not affected.

  • This is all-or-nothing. There's no simple way to allow one approved USB drive while blocking others — every removable disk and every phone gets blocked, or none do. If an agent has a legitimate need for a USB drive, this will block that too.

    • Method 1 — Group Policy (Windows Pro, Enterprise, Education only)

    1. Press Windows + R → type gpedit.msc → Enter.
    2. Navigate: Computer Configuration → Administrative Templates → System → Removable Storage Access
    3. Double-click each of these and set to Enabled:
    SettingAction
    Removable Disks: Deny read accessEnabled
    Removable Disks: Deny write accessEnabled
    WPD Devices: Deny read accessEnabled
    WPD Devices: Deny write accessEnabled

    Click Apply → OK after each one. WPD (Windows Portable Devices) is what catches phones and media players connected via USB/MTP.

    Then run as admin in Command Prompt to apply immediately:

    gpupdate /force

    Method 2 — Registry (works on Windows Home too, no gpedit needed)

    This writes the same policy values gpedit.msc would set, directly to the registry. Open Command Prompt as administrator and run:

    reg add "HKLM\SOFTWARE\Policies\Microsoft\Windows\RemovableStorageDevices\{53f5630d-b6bf-11d0-94f2-00a0c91efb8b}" /v Deny_Read /t REG_DWORD /d 1 /f
reg add "HKLM\SOFTWARE\Policies\Microsoft\Windows\RemovableStorageDevices\{53f5630d-b6bf-11d0-94f2-00a0c91efb8b}" /v Deny_Write /t REG_DWORD /d 1 /f
reg add "HKLM\SOFTWARE\Policies\Microsoft\Windows\RemovableStorageDevices\{6AC27878-A6FA-4155-BA85-F98F491D4F33}" /v Deny_Read /t REG_DWORD /d 1 /f
reg add "HKLM\SOFTWARE\Policies\Microsoft\Windows\RemovableStorageDevices\{6AC27878-A6FA-4155-BA85-F98F491D4F33}" /v Deny_Write /t REG_DWORD /d 1 /f
gpupdate /force

    If gpupdate /force doesn't seem to take effect immediately, restart the laptop — the registry-direct method occasionally needs a reboot to fully apply, unlike the GPO method.

    Verify

    Plug in a USB flash drive and try to open it. You should see: Location is not available — Access is denied. Also confirm keyboard/mouse still work normally (they will — different device class).

    To reverse

    GPO method: set each of the four settings back to "Not Configured" in gpedit.msc, then gpupdate /force.

    Registry method: delete the four values (or the two GUID keys entirely) from HKLM\SOFTWARE\Policies\Microsoft\Windows\RemovableStorageDevices, then gpupdate /force or restart.

    Known Gotchas

    • Missing "www." — the hosts file needs an exact match. If a site still loads, check the browser's address bar for the exact domain (with or without www) and compare against this list.
    • Local country domains — some betting sites use a Zambia-specific address (e.g. betway.co.zm, betpawa.co.zm) separate from their global .com. If a site still works, check whether it's using a local domain not yet on this list.
    • Secure DNS (DoH) — if Chrome or Edge has "Use secure DNS" turned on, it can bypass the hosts file entirely. Check Settings → Privacy and Security → Security in both browsers.
    • Android emulators (e.g. BlueStacks) — these run their own network stack and do NOT respect the Windows hosts file. If one is installed on a laptop, everything above can be bypassed from inside it — worth checking whether it's present and handling separately.
    • After any edit: always run ipconfig /flushdns and fully close/reopen the browser before testing.
